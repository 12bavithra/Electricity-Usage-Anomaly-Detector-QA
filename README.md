# Electricity Usage Anomaly Detector – QA Testing

## Project Overview
This project focuses on manual functional testing of an existing Electricity Usage Anomaly Detector application built with Streamlit. The application allows users to upload electricity usage data, view usage charts, and identify unusual consumption patterns.

## Testing Objectives
- Verify CSV file upload functionality.
- Validate required columns and input data.
- Test application behavior with valid and invalid data.
- Verify simulation, usage charts, and anomaly alerts.
- Check that displayed alerts match the anomaly results table.

## Testing Scope
- CSV upload and data display
- File format validation
- Required-column validation
- Invalid and missing data handling
- Simulation and chart display
- Anomaly alerts and results table

## Tools Used
- Manual Testing
- Microsoft Excel – Test Case Documentation and Execution Report
- GitHub – Version Control and Project Documentation

## Test Documentation
The Excel workbook contains 15 test cases, including test steps, test data, expected results, actual results, status, and remarks.

## Project Outcome
Documented and checked 15 functional test scenarios covering CSV uploads, input validation, chart behavior, and anomaly alerts. Recorded the test results and organized the QA documentation for review.

## Note
Testing was performed on the listed scenarios. The results represent the scope covered by this test suite and do not guarantee that every possible application behavior has been tested.
